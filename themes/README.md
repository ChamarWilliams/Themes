# Shopify Themes

This folder is the source workspace for storefront themes and website GUI experiments connected to the Dropshipping Department.

## Themes

- `shop1-conversion-theme`: Starter Shopify OS 2.0 theme for `E-Commerce Branch > Dropshipping Department > Shopify > Shop1`.
- `shop1-white-commerce-theme`: Primarily white, crisp marketplace-style Shopify theme.
- `shop1-cream-commerce-theme`: Warm cream, curated-shopping Shopify theme.

## GitHub Destination

Theme source files are intended to live in the private GitHub repo configured by `GITHUB_REPO`.

Recommended repository path:

```text
themes/shop1-conversion-theme/
```

Keep raw Liquid/theme source files in GitHub. Use generated zip files only for manual Shopify upload when needed.
